# Python visualisation exercises

These notebooks demonstrate a progression from static charts to interactive and geographic visualisation:

- Matplotlib line plots;
- area plots, histograms and bar charts;
- pie, box, scatter and bubble plots;
- waffle charts, word clouds and regression plots;
- map generation; and
- Plotly basics.

The exercises use course datasets and supplied instructions. They are presented as evidence of practical chart selection and implementation, not as original ownership of the teaching material or data. Course attribution remains inside the notebooks.

Saved outputs and notebook checkpoints were removed from the Git-ready copies to keep the repository compact and free of machine-specific state. Exact originals remain in the ignored local archive.
