# Flower dataset note

`flower.csv` is a tab-delimited dataset with 96 observations and eight variables: `treat`, `nitrogen`, `block`, `height`, `weight`, `leafarea`, `shootarea` and `flowers`.

The file matches the companion flower dataset documented in the [importing-data chapter of *An Introduction to R*](https://intro2r.com/importing-data.html). It is retained here with that attribution so the accompanying R exercise remains reproducible. The referenced chapter did not present a separate dataset licence during the October 2026 audit, so this repository makes no claim of ownership or open-licence status.
