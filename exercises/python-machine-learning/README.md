# Python machine-learning exercises

This collection records hands-on practice across regression, classification, clustering and recommendation systems.

## Topics represented

- simple, multiple, polynomial and non-linear regression;
- k-nearest-neighbour, decision-tree, logistic-regression and support-vector classification;
- k-means, hierarchical and DBSCAN clustering; and
- content-based and collaborative-filtering recommendation.

The separate [loan-classification assessment](../../projects/loan-classification-assessment/) applies several of these methods in a final comparative exercise.

The notebooks originated in IBM Skills Network/Coursera labs and retain their source attribution and supplied narrative. They demonstrate the code completed or adapted during study; this repository does not claim authorship of the course prompts or datasets.

Outputs and transient metadata were removed from the review copies. Some notebooks download public course snapshots, so network availability and upstream URLs can affect reruns.
