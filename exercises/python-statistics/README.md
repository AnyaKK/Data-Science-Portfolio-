# Statistics with Python exercises

These notebooks cover descriptive statistics, probability distributions, hypothesis testing, regression analysis and statistical visualisation. The code uses pandas, NumPy, SciPy, statsmodels, Matplotlib and seaborn where required by the individual exercise.

This folder complements the standalone [Boston housing statistics assessment](../../projects/boston-housing-statistics/), which provides a more complete hypothesis-testing and regression example.

The notebooks began as IBM Skills Network/Coursera learning material. Their original attribution is preserved, and they are described here as completed or adapted exercises rather than wholly original tutorials. Saved outputs and local notebook metadata were removed; unchanged originals remain in the ignored local archive.
