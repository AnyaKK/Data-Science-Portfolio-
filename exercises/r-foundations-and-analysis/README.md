# R foundations and data-analysis exercises

These 14 R-kernel notebooks record practice with vectors, factors, arrays, matrices, data frames, HTTP requests, web scraping, charting, tidyverse data acquisition, data wrangling, exploratory analysis, model development and model evaluation.

The exercises use R packages named in their individual setup cells, including tidyverse components, `httr`, `rvest` and modelling packages. They complement the standalone [COVID-19 analysis](../../projects/covid19-r-analysis/), [weather API exercise](../weather-api-r/) and [spatial infrastructure assessment](../../projects/spatial-infrastructure-r/).

The notebooks began as IBM Skills Network/Coursera labs. Their original teaching narrative and attribution remain; the repository presents them as completed or adapted practice, not wholly original course content.

Saved outputs, checkpoints and machine-specific metadata were removed from the Git-ready copies. A literal copy of every discovered R/Python source file is retained in the ignored local archive.
