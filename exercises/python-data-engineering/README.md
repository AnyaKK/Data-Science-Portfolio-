# Python data-engineering exercises

This six-notebook set demonstrates small extraction, web-scraping and ETL workflows:

- accessing a public API;
- completing an API-extraction assessment;
- parsing web pages and tables;
- completing a web-scraping assessment;
- extracting, transforming and loading tabular data; and
- completing an ETL assessment.

Account-specific Db2 notebooks and any credential-bearing originals are deliberately not included here. They remain in the ignored local archive pending a separate security review. The review copies in this folder do not require private account credentials, although public network endpoints may change.

These exercises originated in IBM Skills Network/Coursera material. Original attribution remains in the notebooks, and the portfolio presents them as evidence of practical completion rather than authorship of the supplied prompts.
