# Python data-analysis exercises

This five-notebook sequence follows a compact analysis workflow:

1. importing and inspecting data;
2. cleaning and transforming variables;
3. exploratory analysis and relationships;
4. regression-model development; and
5. evaluation and refinement.

The notebooks use pandas, NumPy, Matplotlib, seaborn, SciPy and scikit-learn on course-provided examples. Together they demonstrate data-type handling, missing-value treatment, descriptive summaries, correlation, visual exploration, linear and polynomial regression, pipelines, cross-validation and model diagnostics.

The material began as IBM Skills Network/Coursera review labs. Original attribution remains in each notebook. Outputs and local execution metadata were removed while preparing the review copies; unchanged originals are kept in the ignored local archive.
