# Business-intelligence exercises

This folder contains three separate coursework artifacts covering Excel analysis, Power BI report design and a static automotive dashboard export. They should be reviewed as individual exercises; the files do not all use the same data model.

## Artifacts

### Excel car-sales workbook

[car-sales-workbook.xlsx](car-sales-workbook.xlsx) contains an instruction sheet, 1,200 car-sales records for 2018 and 2019, and pivot summaries for quantity and profit. The source table contains five vehicle models and ten dealer IDs. Its assignment asks for quantity-by-dealer and profit-by-date/model/year/dealer charts, including a Hudson-model dealer view.

### Power BI report

[dashboard-development.pbix](dashboard-development.pbix) contains three report pages:

- `sales test data`, with cards plus bar, line and pie charts over sales and product tables;
- `procdata`, with work-order fee, labour, wait-time and service visuals;
- `procurement data3`, with budget views by time, category, status, sourcing manager and country.

Open the file in Power BI Desktop to inspect the interactive report, data model, filters and measures.

### Static automotive dashboard

[car-sales-and-service-dashboard.pdf](car-sales-and-service-dashboard.pdf) is a two-page dashboard export. The first page presents profit and quantity-sold KPIs with model and dealer breakdowns. The second page presents recalls by model and affected system, monthly quantity/profit, and customer sentiment.

## Viewing the files

- Use Microsoft Excel or a compatible spreadsheet application for the workbook.
- Use Power BI Desktop for the `.pbix` report.
- Open the PDF in any standard PDF viewer.

These files preserve the original course content and embedded attribution. Personal document metadata and local machine paths were removed from the published workbook without changing its visible worksheets.
